数据安全

iPhone / iPad 上数据为什么会「消失」？
  • 无痕（隐私）浏览
    关掉窗口就清空，什么都不留 —— 别在无痕窗口里记账。
  • 「主屏幕图标」和 Safari 标签页是两套存储
    在哪个入口记的，就只能回哪个入口看，互不相通。固定用一个入口。
  • 清除历史记录与网站数据 / 阻止所有 Cookie
    前者清空本机记录；后者让保存直接失败（页面顶部会出红条提醒）。
  • 系统回收与换容器
    iOS 可能回收长期没打开的网站的脚本存储；换浏览器、换手机、用微信等 App 的内置浏览器打开，也都是不同的存储空间。
  • 正确的用法
    固定一个入口 + 每周点一次「复制备份」或「立即备份」，把 JSON 存进备忘录 / 文件 App（iCloud 会同步）。换设备时用下面的「导入」恢复。

ℹ️

关于

  • 纯静态、零依赖
    全部代码是 HTML/CSS/JS，无构建步骤，可直接部署到 GitHub Pages。
  • 数据不出本机
    使用 localStorage 存储，键名 fatloss.records.v1 与 fatloss.settings.v1，不向任何服务器发送数据。
  • schema 版本
    当前版本 v，导入旧版本数据会自动补齐字段。
  • 食物库为参考值
    内置营养数据取自常见食物成分表，属于近似值，允许手改或保存自定义食物。
