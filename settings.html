ℹ️

关于

  • 纯静态、零依赖
    全部代码是 HTML/CSS/JS，无构建步骤，可直接部署到 GitHub Pages。
  • 数据不出本机
    使用 localStorage 存储，键名 fatloss.records.v1 与 fatloss.settings.v1，不向任何服务器发送数据。
  • schema 版本
    当前版本 v，导入旧版本数据会自动补齐字段。
  • 食物库为参考值
    内置营养数据取自常见食物成分表，属于近似值，允许手改或保存自定义食物。
